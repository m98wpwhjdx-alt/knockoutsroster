# Anaesthesia Airway + Ventilator App Prototype

Modern React/Vite prototype for an anaesthesia airway and ventilator decision-support app.

## Included device profiles

- GE Carestation 750
- Mindray WATO EX-55 Pro
- Dräger Primus

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Safety note

This prototype is educational decision support for trained anaesthesia clinicians. Confirm all settings using the actual anaesthesia workstation, manufacturer IFU, patient condition, and local institutional protocol.
